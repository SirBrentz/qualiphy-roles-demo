# Qualiphy roles and permissions demo

Clickable mockup of a proposed roles and permissions model for clinic users and Qualiphy staff. Fake data only; nothing here is connected to Qualiphy.

Open the live page: https://sirbrentz.github.io/qualiphy-roles-demo/

- **Permissions:** click any cell to change who can do what.
- **Preview as:** compares what two roles see in the portal.
- Changes stay in your browser. **Reset changes** restores the starting state.

Generated from a private working repo; edits belong there, not here.
