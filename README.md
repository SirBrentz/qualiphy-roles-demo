# Qualiphy roles and permissions demo

Clickable demo of a proposed Roles & Permissions feature in the Qualiphy clinic portal:

- **Managers tab:** gets a Role column and a Change Role option.
- **New Roles & Permissions tab:** the clinic Admin creates roles and chooses what each role can do.

Fake data only; nothing here is connected to Qualiphy.

Open the live page: https://sirbrentz.github.io/qualiphy-roles-demo/

- Start the walkthrough (10 steps, about 3 minutes) or explore on your own.
- Changes stay in your browser. **Reset** starts over.

Generated from a private working repo; edits belong there, not here.

Icons are react-icons (MIT) glyphs from Font Awesome Free, Tabler, Boxicons, Material, Bootstrap Icons, Typicons, Ionicons and Remix Icon; their licences are listed in `icons.js`.
